# 原厂资料索引（已排除视频）

这里保存从移动硬盘学习资料中筛选出的开发相关文件。原始资料仍保留在移动硬盘，本目录只是方便工程使用的副本。

## 01_整车与远程控制

- `远程驾驶车操作及学习手册.pptx`：原厂网页上位机使用手册，资料中的入口为 `nrc.smartcar.run`。
- `5G通讯.docx`：RM500U、SIM 卡和 `frp + networkrc` 的说明。

旧 FRP 配置中的公网 IP、token 和示例 Wi-Fi 密码没有复制进来。这些信息年代较久，也不适合作为新工程默认配置。

## 02_C++赛道案例

按原资料顺序保存：

1. 树莓派 OpenCV 4.2 C++ 环境配置。
2. CMake 与摄像头演示。
3. ROI、灰度、高斯滤波、Canny。
4. 扫线循迹。
5. PD/PID 转向计算。
6. 蓝色障碍物识别与绕障。
7. 颜色触发和停止。
8. 语音交互的 C 示例（不含庞大的 SDK 与音视频文件）。

这些是原始参考代码，不代表已经修复或可以安全直接控制车辆。可运行的新代码位于项目根目录的 `src/` 和 `include/`。

## 03_电机舵机

- `电机舵机驱动文档.docx`：原厂 PWM 参数说明。
- `original_motor_test.py`：原始 Python 案例，仅用于核对参数。

原资料对舵机使用编号 `12`，但注释写成“GPIO17”，存在冲突；上车确认前不要据此输出 PWM。

## 04_Python视觉案例

保存原资料中的灰度/Canny/圆形检测、颜色追踪、人脸识别和二维码识别 Python 示例。
这些文件只作为历史参考，新版可运行代码位于项目的 `python/xtnetrc_vision/`。

原资料的云端手势示例包含硬编码的第三方 API 凭据，因此没有复制；这些旧凭据应视为已经泄露并在原服务后台撤销。

## 05_XT-NetRC车辆规格

- `XT-NetRC车辆规格与控制建模.md`：厂家、底盘、主控、摄像头、电调、电机、舵机、通信、导航和软件参数汇总。
- `sources/`：保存的 2023 产品介绍与比赛规则，以及仅供版本对照的 2024/2025 PDF。
- 公开资料没有轮胎、轴距和轮距的正式尺寸；规格文档给出了带可信度标记的图片估算与实车测量表。

## 06_原车SD卡程序_2025

- 从实车 SD 卡只读导出的 C++/Python/OpenCV/TensorFlow Lite/pigpio 参考工程。
- 包含完整循迹、路面分割、避障、变道、斤马线和停车代码，以及单项 Python 识别脚本。
- 已排除视频、编译产物、日志和所有网络/账号凭据。详细系统版本、GPIO/PWM 参数和参考结论见该目录 `README.md`。
