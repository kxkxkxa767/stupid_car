# XT-NetRC 原车 SD 卡程序索引

检查日期：2026-08-29

本目录是从用户提供的原车 SD 卡中做的只读源码归档。已排除编译目录、日志、视频、Shell 历史、FRP 配置、Wi-Fi 密码和其他账号凭据。原 SD 卡未被修改。

## 实际系统信息

- 根文件系统：Debian 12 `bookworm`，64 位 Raspberry Pi 系统。
- 该卡的系统镜像基础日期为 2025-05-13，程序最后修改到 2025-12-28。这不代表整车是 2025 年款；实车仍按用户确认的 2023 批次记录。
- 主机名：`pi`。
- 唯一普通用户：`5G`，UID 1000，属于 `sudo`/`gpio`/`video`/`dialout`/`i2c`/`spi`/`netdev` 等组。系统中没有 `pi` 用户。
- SSH 服务已启用。`127.0.1.1` 和 `::ffff:127.0.1.1` 都是本机回环地址，不是 Mac 可以连接的局域网地址。
- 网络由 NetworkManager 管理，存在一个自动 DHCP 的 Wi-Fi 配置。归档中未保存 SSID 密码。
- `/usr/local` 中自行编译了 OpenCV 4.13.0；系统包库同时留有部分 OpenCV 4.6.0 动态库。原车 CMake 通过 `find_package(OpenCV)` 选择实际环境。

登录时应先使用用户名 `5G`。本次检查没有读取或导出密码哈希，也没有尝试破解原密码。

## 目录用途

- `main/studyroad/`：最新且唯一在主循环中同时启用转向和电机输出的集成版本，最后修改于 2025-12-28。包含 TFLite 路面分割、循迹、蓝色障碍物、黄色锥桶、斤马线、变道和停车状态机。
- `main/studyall/`：较早的分割+全流程版本，主循环中的转向和电机调用已被注释。
- `main/Threshold/`：传统阈值/颜色处理版，转向保留，电机调用已被注释。
- `main/view/`：带分割、多类识别和调参显示的调试版，电机调用已被注释。
- `main/saoma/`：二维码识别小程序。
- `OpenCV/`：Python 颜色、A/B、左/右、斤马线和相机测试脚本。
- `PWM/`：Python/pigpio 电机和舅机标定脚本。
- `imu/`：GPS 和 IMU 串口参考程序。
- `tflite/` 与 `tfliteint8/`：TensorFlow Lite 分割模型调用样例及模型。

## 原车控制参数

| 对象 | GPIO（BCM） | 频率 | pigpio range | 原程序数值 |
|---|---:|---:|---:|---|
| 底盘转向舅机 | 12 | 50 Hz | 1000 | `studyroad`: 右 60 / 中 70 / 左 80 |
| 电调/驱动电机 | 13 | 200 Hz | 40000 | 中性 10000，注释记录约 10200 开始前转、9800 开始反转 |
| 云台 X | 22 | 50 Hz | 1000 | `studyroad` 初值 73 |
| 云台 Y | 23 | 50 Hz | 1000 | `studyroad` 初值 75 |

最新 `studyroad` 的常规循迹参数为 `Kp=0.21` 、`Kd=0.80`，输入是 160×128 分割图上的像素中线误差。这组 PD 参数与摄像头姿态、图像尺寸、处理延迟及舅机安装都绑定，不能直接当作 Pure Pursuit 的参数。

卡内其他版本中出现过 70、84、99 三种不同的舅机中值，说明实车曾重新安装或标定舅机。首次上电不应猜测中值；必须让车轮离地，并从中性值小幅度调整。

## 对新工程的参考结论

1. 保留新工程的 Pure Pursuit 横向控制；原车 PD 用作传感器/执行器校验参考，不直接复制。
2. 后续增加一个单独的 Raspberry Pi 执行器适配层，把“目标转角/速度”映射成 GPIO 12/13 的已标定 PWM；适配层不应和路径跟踪算法混在一个文件中。
3. 可借鉴原车的避障/变道/停车状态机，但应把“帧计数”改为实际时间，并增加摄像头失败、推理失败、通信断开时的中性停车。
4. 原车电调程序包含较大的正反向命令和反向刹车，未完成实车标定之前不应运行 `studyroad` 的原二进制或原主程序。
