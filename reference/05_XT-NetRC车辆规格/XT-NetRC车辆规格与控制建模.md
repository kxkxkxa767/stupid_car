# XT-NetRC 车辆规格与控制建模记录

更新日期：2026-08-27

适用实车：用户确认的 2023 年 XT-NetRC 批次。本文以 2023 产品介绍和随车学习资料为主；2024/2025 文件仅用于识别后续版本差异。

## 结论摘要

- 正式型号：`XT-NetRC`，早期资料名为“5G 远程驾驶无人车”。
- 当前实车按 2023 批次记录，不能默认套用 2024/2025 比赛版部件。
- 公开采购信息确认品牌/供应商为北京小豚科技有限公司（公开采购中也简称“小豚科技”）。
- 公开资料能够确认底盘、主控、相机、电调、舵机、导航和通信参数。
- 厂家资料未公布轮胎和轴距，但用户提供的实车卡尺照片已确认：轮胎外径 110.63 mm、轮胎宽度 49.52 mm、轴距 238.61 mm。
- 前后轮距、负载滚动周长、整车质量、传动比和编码器参数仍待确认。

### 当前实车 SD 卡软件现状

2026-08-29 对原车 SD 卡做只读检查后确认：卡内实际是 Debian 12 `bookworm` 64 位 Raspberry Pi 系统，程序更新到 2025-12-28；`/usr/local` 中安装了 OpenCV 4.13.0，系统包库还留有部分 OpenCV 4.6.0 库。因此上表的 Ubuntu/Python 3.8/OpenCV 4.2 只表示 2023 随车资料所描述的原配环境，不代表这张卡的当前状态。

该卡的唯一普通用户为 `5G`，主机名为 `pi`，SSH 服务已启用。源码和详细硬件控制参数已归档到 `reference/06_原车SD卡程序_2025/`，不包含 Wi-Fi、FRP 或登录凭据。

“四轮差速驱动”很可能是指四驱底盘中的前后/左右差速机构，不应直接理解为四轮独立电机的滑移转向。实车采用阿克曼舵机转向，因此控制模型应先按自行车模型处理，再根据实车转弯实验修正。

由无负载轮胎外径可得到：

- 几何半径：`r0 = 55.315 mm = 0.055315 m`
- 几何周长：`C0 = πD0 ≈ 347.55 mm = 0.34755 m`
- 自行车模型轴距：`L = 0.23861 m`

轮胎有明显软胎和深花纹，实际承载半径会比 55.315 mm 小；里程计不能直接使用几何周长 347.55 mm，应采用落地滚动实测值。

### 先前图片估算的修正

此前根据厂家示意图估算外径 95-105 mm、轮宽 35-45 mm。实测分别为 110.63 mm 和 49.52 mm，说明厂家示意图不适合用作机械尺寸比例尺；后续以实测值为准。

### 实车测量方法（用于控制）

1. 轮胎外径 `D0`：卡尺测无负载外径，只用于备件筛选。
2. 有效周长 `C_loaded`：装好电池并让车辆落地，在轮胎和地面做标记，直线滚动 5 圈，测总距离后除以 5。里程计使用 `r_eff = C_loaded / (2π)`。
3. 轴距 `L`：前轮转向节中心到后轴中心的水平距离。Pure Pursuit、Stanley、LQR 和 MPC 都需要它。
4. 轮距 `T_f/T_r`：同一车轴左右轮胎接地中心线距离。
5. 最大转角：固定多个舵机 PWM 值，分别测左右前轮转角，建立 `PWM → 实际转角` 标定表。
6. 速度标定：驱动轮离地检查方向后，再在低速封闭场地测量 `PWM → 稳态速度`；不得直接以公开的 40 km/h 作为控制上限。

## 对运动控制方案的影响

- 当前公开配置没有确认轮速编码器，因此不能假设已经具备闭环速度 PID。先检查电机、接收机或附加控制板是否有编码器接口。
- GPS 更新率仅 1 Hz、定位精度约 2.5 m，不适合作为赛道内层转向控制反馈，只适合低频定位或记录。
- IMU 可用于航向角速度和视觉短时丢线补偿，但需要先确认串口协议、安装朝向和零偏。
- 推荐横向控制：鸟瞰路径点 + Pure Pursuit + 曲率前馈；拿到轴距和舵机标定表后再落地。
- Pure Pursuit/自行车模型可先使用实测轴距 `L = 0.23861 m`；正式运行前仍需完成舵机 PWM 到实际前轮转角的标定。
- 推荐纵向控制：有编码器则速度 PID；无编码器则采用油门标定表、斜坡限速、弯道降速和丢线停车。
- 实车最高速度公开为 40 km/h，自动驾驶开发初期应限制在远低于该值的安全速度，并让驱动轮离地完成首次方向和失控保护验证。
