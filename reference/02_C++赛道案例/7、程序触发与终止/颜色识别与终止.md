# 颜色识别

## 一、转换颜色空间

通常，相机在 RGB 颜色模式下工作，但这种模式受到光线的影响较大，所以在opencv中，用HSV（色彩、饱和度、亮度）模型对颜色进行定义。我们可以使用opencv中cvtColor()函数来改变图像的颜色空间。

```cpp
	cvtColor(roi, HSV, COLOR_BGR2HSV);
```

## 二、筛选颜色

OpenCV中的inRange()函数可实现二值化功能，可以同时针对多通道进行操作，使用起来非常方便。主要是将在两个阈值内的像素值设置为白色（255），而不在阈值区间内的像素值设置为黑色（0），我们通过他来将指定的颜色筛选出来。

**inRange 函数参数解释：**

​	参数1：输入要处理的图像，可以为单通道或多通道。
​	参数2：包含下边界的数组或标量。
​	参数3：包含上边界数组或标量。
​	参数4：输出图像。

## 三、检测颜色轮廓

OpenCV中的findContours()函数可实现检测物体轮廓功能。可以将识别到的颜色坐标信息以Point类型存储起来。

```cpp
	vector<vector<Point>> contours;
	findContours(binary, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
```

## 四、圈定范围

OpenCV中的boundingRect()函数可以实现用一个最小的矩阵，把找到的信息包起来，能够返回包围轮廓的矩形的边界信息。

**boundingRect 函数参数介绍：**

​	参数1：灰色图像或者轮廓。

​	返回值：矩形边界左上角顶点的坐标值及矩形边界的宽和高。

```cpp
	if (contours.size() == 0) {
		return Rect();
	}
	else {
		return boundingRect(contours[0]);
	}
```
